| ACT3 | 🐞 **BUG — `NextCode` (`gormstore/codesequence.go`) reads the counter row then writes `next_number+1` with no CAS guard and no row lock, so two ordinary concurrent `Create<Type>` calls (`CreateActor`/`CreateGroup`/`CreateGroupType`/`CreateHierarchy`/`CreateLevel`/`CreateRoleKind`, everyday operations — a raced call is not a contrived scenario) can fail outright with a raw, unclassified database error.
