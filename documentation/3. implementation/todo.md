This corrects a prior sweep's own note (still on this board as ACT1's trailing observation) that called this gap "unreachable today" — that description belongs only to ACT1's *own* finding (a `Unique`-attribute race with no `Unique` attribute yet defined to race on); `NextCode` itself is called directly by `CreateActor`/`CreateGroup` on every single invocation and is fully reachable now.** `NextCode` does `SELECT ...
